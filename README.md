# Torrent Tools

这是一个专门针对 Torrent 相关内容管理的工具集合，使用 Go 语言开发，前期主要是一些单体的工具为主。

有设想过未来可能会提供一个 Web 界面来方便操作，但很显然现在是没这样做的。

## 已有工具

- Torrent Match: **种子文件匹配** 将本地以存在的文件按种子内文件名进行软连接

## Torrent Match 种子文件匹配

```
Usage:
  torrent-match <torrent_path> <storage_path> [symlink_target_path] [flags]

Flags:
  -h, --help                  help for torrent-match
      --ignore-torrent-name   创建的软连接路径中忽略种子名
      --only-match            只输出匹配成功的文件
```

使用说明：

最少提供两个参数，第一个是种子或储存种子的目录，第二个是储存文件的目录，第三个参数是可选的创建软连接的目录

会扫描种子内的文件与储存目录下的文件，并尝试进行 hash 比对（仅校验第一个完整块），如果相同则按照种子内文件布局创建软连接。

如果指定了参数三，则会在第三个参数的目录下按照种子文件内的结构创建软连接，如果省略则在参数二的目录下创建。

本方案对大文件识别效果较好，小文件可能因为块大小问题，没有独立的hash块而无法创建软连接。

⚠️ Tips: 软连接后添加种子请务必重新校验，不保证链接文件一定正确。

后期可能会根据已有软连接关系二次校验小文件，以增加小文件匹配成功率（暂不支持）。
